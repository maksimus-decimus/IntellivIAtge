INSTRUCCIONES - Avatares Personalizados
========================================

Pon aquí tus 5 imágenes con estos nombres EXACTOS:

  avatar1.jpg
  avatar2.jpg
  avatar3.jpg
  avatar4.jpg
  avatar5.jpg

FORMATOS ACEPTADOS:
  - JPG / JPEG (tus archivos)
  - También funciona con PNG o WebP

TAMAÑO RECOMENDADO:
  - 200x200 píxeles o más
  - Proporción 1:1 (cuadrada)

DESPUÉS DE AGREGAR LAS IMÁGENES:
  1. Guarda este proyecto
  2. Ejecuta: flutter pub get
  3. Ejecuta: flutter run -d chrome
  4. Ve a la pestaña "Perfil"
  5. Click en el botón de editar (lápiz verde)
  6. ¡Tus 5 avatares aparecerán en el selector!

Ubicación actual: assets/images/avatars/

IMPORTANTE: En el código Flutter, las rutas son 'images/avatars/avatar1.jpg'
(sin el prefijo 'assets/' porque Flutter lo añade automáticamente)
